Импорт фильмов из YAML

Импорт выполняется от имени user (администратор). Файл должен содержать массив movies.

Формат файла

Каждый фильм описывается объектом в массиве movies. Для ролей director, screenwriter и operator используется вложенный объект: укажите id существующей персоны либо блок data, чтобы создать новую.

Внутри data доступны те же поля, что и в форме создания персоны. Можно указать locationId или передать вложенный блок location, тогда локация создастся автоматически. 

movies:
  - name: "Example Movie"
    coordinates:
      x: 12.5
      y: 480
    oscarsCount: 1
    budget: 5000000
    totalBoxOffice: 18.7
    mpaaRating: "PG_13"
    goldenPalmCount: 2
    genre: "DRAMA"
    director:
      id: 2
    screenwriter:
      data:
        name: "New Writer"
        weight: 62.3
        nationality: "GERMANY"
        location:
          name: "Studio A"
          x: 42.0
          y: 15.5
    operator:
      data:
        name: "Camera Pro"
        weight: 70.0
        nationality: "SPAIN"
        locationId: 3
